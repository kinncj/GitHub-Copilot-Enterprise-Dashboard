Understanding Your Metrics

Generations

How many times Copilot was triggered — code completions, inline suggestions, and agent mode prompts. Measures usage intensity, not how much code was produced. Used by: Power Users insight, Activity Timeline, Top Users by Generations.

Lines of Code

Actual code written or deleted (loc_added_sum / loc_deleted_sum). Measures output volume — varies by language, task type, and coding style. Used by: Top Users by Lines Added, LoC Trend, Value estimates.

Acceptance Rate

% of code completions that were kept. ⚠ Treat with caution — ~94% of activity is agent mode, which does not record acceptances. A low rate is not a red flag; it likely reflects agent usage, not rejected suggestions.

These metrics tell different stories. A user with 5,000 generations and 200 lines is doing intensive chat/refactoring work. A user with 500 generations and 8,000 lines is writing large files with few prompts. Neither pattern is better — they reflect different working styles.

Feature Modes — what each one means
Code Completion — passive inline suggestions (grey ghost text). Zero clicks required; Copilot predicts as you type.
Edit Mode — you describe a change in plain English; Copilot edits across multiple files at once. You review a diff before accepting.
Agent Mode — like Edit Mode but autonomous: Copilot plans, runs commands, reads errors, and iterates until the task is done. Least human intervention.
Inline Chat — press ⌘I inside the editor to ask a focused question or request an edit without opening the sidebar.
Chat · Ask — question-and-answer mode in the chat panel. Copilot responds but does not modify files automatically.
Chat · Agent / Plan — agent or planning mode accessed through the chat panel rather than the editor toolbar. Same autonomy as Agent Mode, different entry point.

Rule of thumb: Code Completion = fastest, least effort. Inline Chat = targeted questions. Edit Mode = multi-file rewrites with a review step. Agent Mode = hands-off automation. The more agentic the mode, the fewer acceptances are recorded — which is why a low acceptance rate is normal.
